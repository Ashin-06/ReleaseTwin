Method

    These tools support controlled experiments. A passing run is evidence about the supplied inputs, not a general security guarantee. Read the repository’s threat model for assumptions and unsupported cases.

    Evidence integrity

    Saved cases are checked for missing or extra files, hash mismatches, and disagreement on replay. A hash manifest detects changes; it does not establish an independent author or trusted timestamp.
